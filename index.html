What is Green Tea Party?

Green Tea Party is a public platform for stewardship: communication supports action, and progress is measured by real contribution.

  • Agency first: build capacity, not passive attention.
  • Place-based: organize work around neighborhoods and communities.
  • Transparent: shared metrics and activity make stewardship visible.

How it works

  1. Start in Prototype mode to explore projects, metrics, and activity using sample data.
  2. Use App mode for the real data path as wallet and contract integrations come online.
  3. Track stewardship health and decide where to contribute next.
